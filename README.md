# GeoTales

A routing application built for future-ready travel and navigation experiences.

## Core Components

* **Visual Map** – Interactive map for exploring locations and routes
* **Navigation & Routing** – Route planning and navigation between locations
* **Adventure** – Travel history and previously explored routes
* **AI Narration** – AI-powered narration and insights about places along the route
* **Achievements** – Track milestones and travel achievements

## Tech Stack

### Frontend

* React
* Next.js

### Backend

* Python
* FastAPI

### Database

* PostgreSQL
* PostGIS

## How to Clone the Repository

### 1. Install Git

Make sure Git is installed on your local system.

### 2. Clone the Repository

Create an empty project folder, open Command Prompt/Terminal inside the folder, and run:

```bash
git clone "repo-link"
```

### 3. Navigate into the Project

```bash
cd GeoTales
```

### 4. Create a New Branch

Create your own branch before making changes:

```bash
git checkout -b "branch_name"
```

### 5. Check Your Branch

```bash
git status
```

You can also verify the current branch with:

```bash
git branch
```
